# Bayview AI Club · 2026–27

Design guidance: ui-ux-pro-max, applied to this club's existing identity.

## Direction

Keep the blue/white identity and mature its hierarchy. The skill's generated education recommendation suggested micro-interactions and clear calls to action; its child-oriented fonts and indigo/green palette were overridden by the explicit brief. Use Inter/system sans, slate text, blue actions, pale blue regions, and small cyan accents.

## Tokens and rules

- Primary/action: #1765ce; ink: #142a43; body: #51657a.
- Surfaces: white, #f0f7fc, #edf5fc; dark learning region: #153b60.
- Content width: 1152px including padding. Desktop sections: 80px; mobile: 56px.
- Hero display: 42–60px; section headings: 28–38px; body: 14–16px.
- Cards serve distinct purposes: elevated next meeting, flat chronological roadmap, tinted leadership, compact archive rows.
- Use Lucide consistently. No emoji icons. Hover changes colour rather than moving content.
- Visible keyboard focus, semantic headings, explicit status text, native disclosures.
- Minimum 44px primary touch targets; respect reduced motion; no continuous animation.
- Byte uses one shared SVG with six poses and unique gradient IDs. Three SVG appearances plus one historical illustration on the homepage.
- Mobile roadmap is a single chronological column. Wrap interest filters with 44px targets and aria-pressed states; preserve phase structure. Executive DOM order stays fixed.

## Audit findings

The original stack, GitHub Pages base, public resource paths, and social channel destinations were retained. Duplicated seasonal announcements and generic card grids were removed. Three published Daily Bits, five historical meeting summaries, six PDFs, two slide decks, root source assets, and legacy archive URLs were preserved. Existing duplicate assets remain for URL compatibility.

No dates, completions, attendance figures, or new resources were invented. The first incomplete meeting is the next planned topic when no current meeting is set.

## Coding and careers revision

Retain the established light blue/white palette and system typography. ui-ux-pro-max’s broad technical query suggested a dark terminal palette, which conflicts with the explicit preservation brief; its semantic control, focus, contrast, and touch-target guidance is applied. Categories use Lucide icons, text labels, and restrained blue/cyan/slate tints. Filters use primary categories plus explicit interest tags, announce result counts, and hide empty phases. Optional math is a nested disclosure, separate from the beginner-facing summary. Career connections stay compact. The four learning pillars form four columns on desktop, two on tablet, and one on mobile.
